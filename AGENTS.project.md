# Project agent skills

Before non-trivial technical work, route with
`.cursor/skills/using-agent-skills/SKILL.md`, then read and follow the matching
skill under `.cursor/skills/<name>/SKILL.md`.

For design, brainstorm, spec review, drift, or any Elephant-Goldfish (EGM)
request, also read `.cursor/skills/using-agent-skills/egm-routing.md`. Open
`egm-brainstorm` even though it sets `disable-model-invocation`. The EGM
package root is `.cursor/egm`.
